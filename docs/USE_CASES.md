# 車窓の使い方を考える

「まだ知らない駅に、降りてみたくなる」を軸にした用途の案です。効果を実証したものではありません。

## 今回の機能でできること

| 場面 | 使い方 | UIとのつながり |
| --- | --- | --- |
| 休日の小さな旅の準備 | 車窓の色から気になる街を開き、地図で位置を見て保存。行き先を決める前のきっかけにする。 | 写真・地図・ハート・保存した駅 |
| 通勤や通学の寄り道 | いつも通過する駅の街並みや由来を知り、帰りに一駅だけ降りる候補をためる。 | 8駅の写真ジャケット・周辺の見どころ |
| 気分から散歩先を選ぶ | 「川辺」「緑」「街歩き」から候補を絞り、地図と写真で決める。 | コレクション・絞り込み・おまかせ |
| 家で短い車窓体験 | 色の帯を眺めながら、気になったところだけ写真に戻す。 | 再生・速度・光の演出・任意の車内音 |

駅をアルバム、雰囲気ごとの集まりをプレイリスト、保存した駅をライブラリとして扱う発想です。現在のコレクションは駅の絞り込みで、曲順のような独自の再生順はありません。車窓は選んだ駅から東横線の駅順に進みます。

## これから広げるなら

- **旅の後のアルバム**：自分の写真と駅を登録して、歩いた日の色を車窓として再生する。写真投稿と色抽出の追加が必要。
- **友人との行き先選び**：保存した駅のリストを共有し、それぞれの「降りたい」を重ねる。今はブラウザ内保存のみで、共有機能は未実装。
- **街の季節を聴き比べるように見る**：同じ駅の春・夏・秋・冬の写真を集め、色の変化を比較する。現状の朝・夜・夜明けは色調の演出で、季節別の実写ではない。
- **地域の小さな案内**：商店街や自治体が提供した写真で、観光名所以外の生活風景を紹介する。地域と写真利用の合意を作る段階が必要。

次の一手としては、保存した駅の共有を小さく試すと、個人の鑑賞から「今度ここ行こう」へつなげやすそうです。現在は、検索・地図・保存・車窓再生の一連の操作を優先しています。
