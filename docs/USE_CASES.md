# 車窓のユーザーストーリー — 検討案

2026年9月5日。企画上の仮説であり、利用者への調査結果や確定仕様ではありません。

## 体験の入口

この作品を開く理由を「知らない街を、しばらく通り過ぎていたい」に置いて考える。
乗って眺める時間そのものが成立し、その途中で一つの風景が気になり、街の名前や場所を知る。
実際の訪問は、その先に起こり得る行動として扱う。

以前の「旅行前の行き先集め」「通勤帰りの一駅散歩」には、この作品を最初に開く理由と、流れる車窓を使う理由の検討が不足していた。
保存・検索・地図があることだけでは、ユーザーストーリーは成立しない。

## 第一案：部屋から、行き先を決めない短い乗車

**場面**：課題や仕事が一段落した夜。同じ部屋で過ごしていた人が、少しだけ別の景色を眺めたくなる。

**したいこと**：何をするか細かく決めず、乗り物に運ばれながら外を眺める時間を持つ。

1. 作品を開くと、窓の向こうを景色が通り過ぎている。路線を詳しく知らなくても乗り始められる。
2. 流れる緑の中に、看板や橋の形が一瞬見える。色だけではなかったことに気づく。
3. 気になったところで速度を落とす。形が見えるようになり、元写真の街が現れる。
4. そのまま眺めてもよい。知りたければ駅名を開くと、場所と短い街の話が分かる。
5. 再び走り出す。途中で終えても、知らない街の橋が少し気になった、という一つの記憶が残る。

**到達点**：短い乗車を心地よく体験し、知らなかった一つの風景に目が留まる。保存や現地訪問は必須にしない。

**未確認の点**：このような気分のときに作品を開くか、操作したくなるか、写真の車窓をもう一度見たいか。

## 第二案：友人の暮らす街を、少しだけ通る

離れた街へ引っ越した友人から、自分の街の写真で作った短い車窓が届く。
受け取った人は、この人はどんな場所で暮らしているんだろう、と思って開く。
商店街の一場面で速度を落とし、送り手が選んだ景色を眺める。
見終わった後に、あの通りが気になった、と会話が始まる。

開くきっかけと風景を見る理由が具体的になる。知らない場所への興味という当初の趣旨にもつながる。
送り手による写真の選択・並べ替えと共有URLが必要。現在は未実装。

## 第三案：旅から帰った後に、あの移動をもう一度

旅行から帰り、移動中に見た景色を思い出したい人が、数枚の写真を順番に並べる。
車窓を再生すると、その日の空や建物の色が流れ、思い入れのある場面ではゆっくり眺められる。
旅の記憶を時間の流れとともに残し、後からまた乗る。

写真の持ち込みと順序・速さの編集が必要。現在は未実装。
思い出の再体験が中心になるため、未知の場所への興味を狙う第一案・第二案とは評価する目的が変わる。

## 速度と写真がストーリーを支える仕組み

初期案の横縞は横方向にほぼ同じ色が続いていた。横移動しても形の変化が乏しく、倍率を上げるだけでは速さの手がかりが増えにくい。
景色の一部が窓に入り、横切り、抜けていくことを見せたい。

| 状態 | 写真・色の見せ方 | 体験上の役割 |
| --- | --- | --- |
| 巡航 | 写真の色と形が横方向ににじみ、木や看板の輪郭が部分的に通過する。 | 乗っている感覚と、一瞬の引っかかりを作る。 |
| 減速 | 横方向への伸びが弱まり、写真の形が連続して見えてくる。 | 自分が気になった風景を見つめられる。 |
| 停車 | 元写真を窓の内側に見せる。駅の情報は必要に応じて開く。 | 街が具体的な場所になる。 |
| 発車 | 写真の形が再び流れる色へと変わる。 | そのまま乗り続けられる。 |

速度は窓一枚分を通過する時間で比較する。試作は1倍で約0.72秒、0.25〜4倍で調整できる。
これは実際の列車速度の再現値ではなく、画面上の見え方を比較するための値。
駅の切替は24秒で、景色の移動速度とは独立している。「ゆっくり見る」では景色を流したまま、駅の切替を保留する。

## 元写真の切り抜きについて

追加で提供された実写の車窓写真をもとに、暗い壁・丸い窓枠・金属の反射を残し、窓の内側だけを表示時に抜く試作を実装した。

- 窓と壁は固定し、風景だけをその奥で動かす。
- 三つの窓から、一続きの風景の別々の範囲が見える。スマートフォンでは中央の窓を大きく見せる。
- 風景は実際の駅周辺写真。速度が上がると横ににじみ、下部の流れを速くして奥行きの手がかりを加える。減速すると元の写真の形が現れる。
- 写真の選び方も必要。手元の新丸子の写真には空・橋・川・手前の柵があり、奥行きを組み立てやすい。一方、元住吉の写真は商店街を正面から見ているため、側面の車窓として横へ流すには構図の検討が要る。

## 次に確かめたいこと

第一案を仮の入口として、実装した車窓を40秒ほど体験してもらう。
「ゆっくり見る」で減速し、窓を押すと元写真が現れ、もう一度押すと発車する。一連の操作と乗っている感覚が伝わるかを確かめたい。

説明を先に与えずに見てもらい、どこで目が留まるか、速度を落としたくなるかを観察する。
その後で何が印象に残ったか、続きを見たいか、気になった街について何を知りたいかを聞く。
実際の訪問意向だけで作品の成否を判定しない。

Spotifyから借りる要素は、路線を選んで乗る・再生を続ける・気に入った景色を残すという操作の分かりやすさ。
車窓を眺める場面では、その体験に注意が向く構成を優先する。
